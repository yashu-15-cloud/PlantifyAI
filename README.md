**PlantifyAI**



**AI-Powered Smart Agriculture Platform**



PlantifyAI is a web-based smart agriculture platform that combines Machine Learning and Deep Learning to help farmers make better decisions.



**Features**

\- Crop Recommendation using Machine Learning

\- Plant Disease Detection using CNN

\- User-friendly Flask Web Application



**Technologies Used**

\- Python

\- Flask

\- HTML

\- CSS

\- JavaScript

\- Machine Learning

\- Deep Learning (CNN)

\- OpenCV

\- PyTorch

\- PlantVillage Dataset



**Project Structure**

\- app.py

\- templates/

\- static/

\- models/

\- data/

\- requirements.txt



**Developed As**

Internship Project – Smart Agriculture using Artificial Intelligence.



**Note:**

The trained AI model files are not included in this repository because they exceed GitHub's web upload size limit. The repository contains the complete source code, project structure, datasets, and training scripts required to reproduce the models.
